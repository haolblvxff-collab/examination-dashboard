# 方案 A：保留功能的轻量化实施计划

## 目标

在保持现有页面流程和功能的前提下，将图表渲染迁移到浏览器端，
把运行依赖收敛为 `FastAPI + Uvicorn + OpenPyXL`，并修复成绩数据安全性和正确性问题。

## 保留功能清单

- 上传 Excel 成绩表并自动分析
- 下载录入模板
- 6 项统计卡片
- 总分/学科/学生/学校趋势
- 学校对比、进步追踪
- 分数分布、箱线图、雷达图、热力图
- 按考试与学校筛选的排名表
- 本地浏览器打开方式及离线使用体验

## 分阶段计划

### 阶段 1：安全与数据正确性

- 服务仅监听 `127.0.0.1`，不向局域网暴露学生数据
- 移除无需开放的跨域配置
- 以 `学校 + 姓名` 识别学生，避免同名合并
- 将 `0` 分作为有效成绩参与统计
- 上传入口仅声明实际支持的 `.xlsx` 格式
- 前端显示用户上传文本时避免 HTML 注入

验收：同名学生、零分和包含特殊字符的姓名均能正确展示，局域网监听已关闭。

### 阶段 2：图表前移与后端瘦身

- 使用本地 ECharts 在浏览器端生成现有图表
- 后端仅承担 Excel 解析、统计、排名和模板下载
- 移除 Python 端 PNG 图表 API 以及 `pandas`、`numpy`、`matplotlib`、`seaborn`

验收：所有原有图表类别与筛选操作可用，后端不再导入重型计算/绘图库。

### 阶段 3：依赖、打包与文档

- 分离运行依赖与构建依赖
- 更新安装方式、技术栈和仅支持 `.xlsx` 的文档说明
- 为后续 PyInstaller 构建保留模板和静态资源打包入口

验收：轻量依赖环境可启动服务，模板可下载，主页面可离线加载图表库。

## 验证清单

- 解析包含多学校、同名学生、多场考试以及 0 分的测试工作簿
- 校验统计 API 与排名 API 返回结果
- 启动本地服务，检查首页、上传、筛选和各图表渲染
- 检查运行依赖中不再包含重型绘图库
